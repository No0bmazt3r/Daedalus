# Extra packages for `./daedalus.sh local` — the whole app on the host, no Docker.
#
# requirements.txt ships `chromadb-client`, which only speaks HTTP to the
# chromadb container. Without that container the vector store has to run
# in-process: the full `chromadb` package, writing to $DAEDALUS_DATA_DIR/chroma
# (the embedded mode in app/db/vector_store.py). The two packages install the
# same `chromadb` module and must not both be present, so `ensure_embedded_chroma`
# in scripts/common.sh removes the client before installing this.
#
# Kept on the same major version as the client, so the on-disk format and the
# API that vector_store.py calls are the ones the container stack uses.
chromadb>=1.5,<2
